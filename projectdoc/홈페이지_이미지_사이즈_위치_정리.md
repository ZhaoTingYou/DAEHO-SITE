# DAEHO 홈페이지 이미지 제작 요청서

업데이트 날짜: 2026-06-22

이 문서는 DAEHO 공식 홈페이지에 들어갈 이미지 제작 및 제공 기준입니다.  
개발용 문서가 아니라, 사진 촬영·렌더링·이미지 제작 담당자가 어떤 이미지가 필요한지 바로 이해할 수 있도록 정리했습니다.

## 전체 이미지 방향

| 항목 | 요청 내용 |
|---|---|
| 브랜드 톤 | 고급 주얼리 브랜드처럼 정제되고 조용한 느낌. 과한 장식, 강한 색감, 복잡한 배경은 피합니다 |
| 기본 배경 | 화이트, 아이보리, 옅은 베이지, 와인 브라운, 블랙을 중심으로 사용합니다 |
| 제품 표현 | 반지와 오브젝트의 디테일, 금속 광택, 각인, 보석 세팅이 선명하게 보여야 합니다 |
| 이미지 안 텍스트 | 이미지 안에는 문구, 로고, 워터마크를 넣지 않습니다. 텍스트는 웹페이지에서 따로 올라갑니다 |
| 여백 | 제품이 너무 꽉 차지 않게 상하좌우 여백을 남깁니다. 특히 모바일에서 잘릴 수 있으므로 주요 피사체는 중앙에 둡니다 |
| 파일 형식 | 일반 사진은 JPG 또는 WebP, 투명 배경 제품 이미지는 PNG 또는 투명 WebP 권장 |
| 해상도 | 아래 표의 권장 사이즈 이상으로 제공해 주세요. 더 큰 원본 제공 가능하면 좋습니다 |

## 3. HERITAGE 공통 상단 이미지

Heritage 하위 페이지 상단은 와인 컬러 배경 위에 중앙 텍스트 박스가 올라가는 구조입니다.  
현재 와인색 배경에 이미지를 추가할 예정이므로, 아래 기준으로 이미지를 준비해 주세요.

| 적용 페이지 | 필요한 이미지 | 권장 사이즈 | 구성 요청 |
|---|---|---:|---|
| LOYALTY 상단 | 관계, 신뢰, 반복 제작의 느낌을 주는 배경 이미지 | 2560 x 1440px / 모바일 1440 x 2200px | 와인 브라운 계열로 톤을 맞춘 이미지. 중앙에는 텍스트 박스가 올라가므로 중요한 피사체를 두지 않습니다 |
| CREDIBILITY 상단 | 기준, 검수, 제작 체계, 공정 관리 느낌의 배경 이미지 | 2560 x 1440px / 모바일 1440 x 2200px | 어두운 와인 톤 또는 저채도 제작 현장 이미지. 복잡한 디테일은 피합니다 |
| ACHIEVEMENT 상단 | 기록, 성과, 대표성, 상징을 보여주는 배경 이미지 | 2560 x 1440px / 모바일 1440 x 2200px | 반지 디테일, 트로피, 기록물 느낌 가능. 중앙 텍스트 영역은 비워 주세요 |

### Heritage 상단 이미지 공통 주의사항

- 배경 위에 연한 카드가 중앙에 올라갑니다.
- 중앙 약 40% 영역에는 중요한 제품 얼굴이나 텍스트가 오지 않게 해 주세요.
- 이미지 자체에 글자를 넣지 않습니다.
- 너무 밝은 이미지보다 와인 브라운과 어울리는 어두운 톤이 좋습니다.
- 원본은 컬러로 제공하고, 필요 시 웹에서 와인색 오버레이를 적용합니다.
