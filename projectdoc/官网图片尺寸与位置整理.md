# DAEHO 官网图片尺寸与位置整理

更新日期：2026-06-22

本文按当前前台页面的真实代码整理图片需求。这里的“尺寸”优先指页面中的显示容器比例和建议交付尺寸，不等同于当前图片文件的原始像素。

## 统一规则

| 项目 | 当前规则 | 素材准备要求 |
|---|---|---|
| 普通内容图片 | 多数通过 `SafeImage` 渲染，`fill + object-cover`，默认 `sizes="(min-width: 1024px) 520px, 100vw"` | 图片会被裁切。主体不要贴边，安全区域建议放在中心 70% 内 |
| 透明产品图 | golf 顶部产品轮播使用 `object-contain` | 推荐 PNG/WebP 透明底，产品边缘不要被裁切，四周留 3%-6% 空白 |
| 背景大图 | 使用 `object-cover`，大多铺满视窗或大面积卡片 | 推荐宽图，主体避开文字覆盖区域 |
| 正方形产品图 | 多用于卡片、making 流程、creations 作品 | 推荐 1600 x 1600，主体居中，留白一致 |
| 横图 | 多用于 home、news、archive | 按下表比例导出，主体居中或偏向当前文案的反方向 |
| 文件位置 | 所有前台图片放在 `public/images/` 下 | 代码中写的是相对 `public/images` 的路径，例如 `golf/1.png` |

| 4:3 横图 | 4:3 | 1600 x 1200 | news featured、news grid、credibility 占位图 |
| 3:2 横图 | 3:2 | 1800 x 1200 | archive、news related |
| 3:4 竖图 | 3:4 | 1200 x 1600 | achievement 记录卡、项目 archive |

## 内部样式页

`/ko/styleguide-internal` 使用 `Hero`、`MediaText`、`ProductGrid`、`TimelineEntry` 等内部展示组件，不作为正式前台页面的图片交付标准。若需要更新内部样式页图片，可按组件比例处理：

| 组件 | 图片比例 |
|---|---|
| `Hero` | 正方形 |
| `MediaText` | `4:5` |
| `ProductGrid` | 正方形 |
| `TimelineEntry` | `3:2` |

## 换图检查清单

1. 图片放到 `public/images/`，路径与 `messages/ko.json` 或代码中引用的文件名一致。
2. 大图优先用 JPG/WebP；透明产品图用 PNG/WebP 透明底。
3. `object-cover` 区域必须检查移动端裁切，尤其是 `16:9 -> 4:3`、正方形、`3:4` 区域。
4. 有文字叠加的背景图，主体不要放在文字侧；creations 分类面板尤其要注意左右渐变文字区域。
5. golf 的 `Mask group.png` 是一张被四个颜色共用的裁切图，不建议拆成四张，除非同步改代码。
6. 新增图片后本地检查：`npm run lint`、`npx tsc --noEmit`、并用浏览器看桌面和移动端。
