# CMS 外部官网链接管理设计

## 背景

官网顶部导航和页脚曾经包含 DAEHO、OH、VULCAN 等关联官网入口。目前这些入口仍以硬编码形式存在，但由前端常量统一隐藏；CMS 只能修改名称，不能配置网址、单独启停、增删或排序。

本次改造将外部官网入口变成一套由 CMS 管理的动态列表，并让桌面端顶部导航、移动端顶部导航和页脚共享同一份配置。

## 目标

- CMS 可以新增、删除、编辑、启停和排序外部官网。
- 每个站点可以分别填写韩文和英文名称。
- 网址、启停状态和顺序在韩文站与英文站之间共享。
- 桌面端顶部、移动端顶部和页脚使用同一份列表。
- 仅渲染已启用且网址有效的站点。
- 保留现有 DAEHO、OH、VULCAN 作为初始记录，并维持默认关闭，避免部署后意外改变线上展示。

## 非目标

- 不在本次改造中增加站点图标、Logo 上传或说明文字。
- 不支持非 HTTP(S) 协议。
- 不为顶部和页脚提供两套独立配置。
- 不改变顶部导航或页脚的整体视觉设计。

## 数据模型

外部官网列表继续归属于 CMS 的 `common` 页面配置，逻辑路径为 `footer.externalSites.items`。每个项目包含：

```ts
type ExternalSiteItem = {
  id: string;
  label: string;
  href: string;
  enabled: boolean;
};
```

CMS 数据仍按 `ko` 和 `en` 保存。两个语言版本拥有相同的项目 `id`、`href`、`enabled` 和数组顺序，只有 `label` 可以不同。

保存时以后端收到的统一项目 ID 顺序作为基准，重新构造韩文和英文数组：

- `id`：稳定标识，用于对齐两种语言的数据。
- `label`：分别读取韩文和英文输入。
- `href`：只读取一次，并同步写入两个语言版本。
- `enabled`：只读取一次，并同步写入两个语言版本。
- 数组顺序：由 CMS 排序结果决定，并同步写入两个语言版本。

初始记录为 DAEHO、OH、VULCAN。现有名称可作为回退值，初始网址为空、状态关闭。

## CMS 交互

在 `/admin/footer` 的“外部官网”区域使用一个统一管理器，不再为韩文和英文分别渲染独立列表。

每一行提供：

- 韩文名称
- 英文名称
- 官网网址
- 开启/关闭复选框
- 上移
- 下移
- 删除

区域顶部提供“新增官网”按钮。新增项目立即生成稳定 ID，并追加到列表底部。保存前可继续编辑、移动或删除。

删除只在提交保存后生效。CMS 至少允许保存空列表。空列表或所有项目关闭时，前台不显示外部官网区域。

网址输入使用链接字段。服务端保存和前台渲染均只接受 `http://` 与 `https://`；无效或空网址即使启用也不会显示。

## 前台读取与渲染

公共消息加载完成后，对外部官网列表执行一次规范化：

1. 确认值为数组。
2. 移除缺少稳定 ID 的异常项目。
3. 只向展示组件提供 `enabled === true` 且网址为有效 HTTP(S) 的项目。
4. 当前语言使用对应的 `label`。

桌面端顶部导航、移动端顶部导航和页脚改为遍历规范化后的列表。三处继续复用现有安全外链组件，在新窗口打开，并附带安全的 `rel` 属性。

旧的 `showExternalHeaderLinks` 与 `showFooterExternalLinks` 代码常量将删除。列表本身成为唯一显示条件。

## 兼容与迁移

- 静态语言文件增加 `items` 默认数组，保留 DAEHO、OH、VULCAN。
- 现有 CMS 记录如果没有 `items`，公共页面自动回退到静态默认数组。
- 默认数组全部关闭且网址为空，因此部署不会自动暴露未配置链接。
- 现有 `footer.externalSites.daeho`、`oh`、`vulcan` 名称字段暂时保留用于兼容旧数据，但从新的 CMS 管理区域移除；完成迁移后前台不再依赖这些固定字段。

## 错误处理

- CMS 保存时拒绝危险协议，空网址可以保存但不会展示。
- 两种语言的名称允许暂时为空；某语言名称为空时可回退到另一语言名称，两个名称都为空则不展示。
- 重复网址不自动合并，避免擅自删除管理员配置。
- 删除、排序和新增均通过稳定 ID 对齐，避免韩文与英文内容串位。

## 测试与验收

自动测试覆盖：

- CMS 页面包含新增、删除、编辑、启停和排序控件。
- 保存后两种语言的 ID、网址、状态和顺序一致，名称分别保留。
- 无效协议、空网址和关闭项目不会出现在前台。
- 有效开启项目同时出现在桌面顶部、移动顶部和页脚。
- 空列表不会留下空白占位。
- 旧 CMS 数据缺少动态列表时安全回退。

人工验收覆盖：

- 在 CMS 新增一个外部官网，分别填写韩文和英文名称，保存后两种语言显示正确。
- 改变排序后顶部和页脚同步更新。
- 关闭或删除项目后，所有展示位置同步消失。
- 在桌面、平板和手机尺寸确认布局没有破坏。
