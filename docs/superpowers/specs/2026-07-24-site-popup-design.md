# DAEHO 全站定时图片弹窗设计

## 目标

为官网增加一个由 CMS 控制的全站公告弹窗，用于暑期休假等临时通知。公告内容暂时只支持一张图片，管理员可以设置图片、显示开关和韩国时间的开始/结束时间。

本次只实现一个当前公告，不建设公告列表、历史记录、文字编辑器或图片跳转链接。

## 已确认的产品规则

- 弹窗覆盖韩文和英文全部公开页面，不出现在 CMS 后台。
- 仅当管理员开启显示、图片存在且当前时间处于有效时间段内时展示。
- 开始和结束时间精确到分钟，固定按 `Asia/Seoul` 解释。
- 用户普通关闭后，本次浏览会话内不再弹出；关闭当前标签页并在新会话访问时可再次出现。
- 用户勾选“不再显示”后，当前这条公告永久不再弹出。
- 管理员更换图片或调整开始/结束时间后，视为一条新公告，之前的“不再显示”不影响新版本。
- 弹窗图片保持原比例完整显示，不裁切。

## CMS 体验

后台侧栏新增“弹窗公告”入口，进入独立设置页。页面提供：

- 显示开关。
- 公告图片。
- 从本地上传图片。
- 从媒体库选择图片。
- 开始日期和时间。
- 结束日期和时间。
- 保存按钮和当前状态提示。

配置独立存储在新的 `site-popup` 页面数据中，不放入首页或 Footer 配置，避免全站设置与现有页面内容互相影响。韩文、英文站点读取同一组配置；保存时同步写入两个 locale 数据，管理员不需要重复维护。

后台保存时执行以下校验：

- 开启显示时必须有图片。
- 开启显示时必须填写开始和结束时间。
- 结束时间必须晚于开始时间。
- 日期输入按韩国时间转换为包含 `+09:00` 的 ISO 时间后保存。

未开启显示时允许保留图片和时间，方便管理员提前准备或临时关闭公告。

## 前台体验

公共站点布局中加入一个客户端 `SitePopup`，因此任何韩文或英文公开页面都能统一展示。组件在页面首次挂载时检查配置、当前时间和浏览器中的关闭记录。

弹窗由以下部分组成：

- 覆盖页面的半透明遮罩。
- 居中的图片容器。
- 右上角关闭按钮。
- 韩文或英文的“不再显示”复选框。

桌面端和移动端均以 `object-fit: contain` 完整显示图片，最大范围约为视口宽度的 `90vw` 和高度的 `75vh`。图片加载失败时不显示空白弹窗，也不阻塞页面。

用户可以通过关闭按钮、点击遮罩或按 `Escape` 关闭。弹窗打开时锁定页面滚动，将焦点放到关闭按钮，并在关闭后把焦点还给原元素。弹窗层级高于 Header、回到顶部按钮和其他悬浮控件。

普通关闭写入 `sessionStorage`；勾选“不再显示”后关闭写入 `localStorage`。复选框本身不立即关闭弹窗，用户仍需执行关闭操作。

## 公告版本

前端根据以下字段生成稳定的公告版本标识：

- 图片地址。
- 开始时间。
- 结束时间。

显示开关不参与版本计算，因此关闭再重新开启同一配置不会打扰已经选择“不再显示”的用户。图片或时间任一字段改变都会生成新版本。

浏览器存储只保存版本标识，不保存用户信息、页面内容或其他个人数据。

## 数据结构

`sitePopup` 使用以下结构：

```json
{
  "enabled": false,
  "image": "",
  "startsAt": "",
  "endsAt": ""
}
```

页面目录新增 `site-popup` 定义，归入设置类页面。通用页面编辑入口访问该配置时重定向到专用的 `/admin/popup` 页面。

## 时间与显示判断

保存后的时间带有明确的 `+09:00` 偏移，不依赖访问者设备时区。前端在组件挂载时使用当前绝对时间判断：

```text
enabled
AND image is not empty
AND now >= startsAt
AND now < endsAt
AND current version is not dismissed
```

结束时间采用不包含边界的判断。组件只在用户进入页面时判断一次，不要求已经打开的页面等待到开始时间后自动弹出。

## 代码边界

预计涉及：

- `lib/cms/page-catalog.json` 和对应类型：登记 `site-popup`。
- `messages/ko.json`、`messages/en.json`：提供默认配置。
- `app/admin/(dashboard)/popup/`：专用 CMS 设置页。
- `app/admin/actions.ts` 或独立 action：校验并保存共享配置，复用现有 S3 上传流程。
- `app/admin/_components/admin-shell.tsx`：增加后台导航。
- `app/[locale]/(site)/layout.tsx`：在全部公开页面挂载弹窗。
- `components/`：新增前台弹窗组件。
- `lib/`：新增可单元测试的时间、版本和显示判断逻辑。

现有媒体库、S3 上传、页面消息合并和认证机制继续复用，不新增数据库表。

## 异常处理

- 配置缺失、日期非法、结束时间早于开始时间或图片为空时，前台静默不展示。
- 后台明确显示校验错误，不提交部分有效的数据。
- `localStorage` 或 `sessionStorage` 不可用时，弹窗仍可关闭，但关闭记录只维持在当前组件生命周期内。
- 图片请求失败时自动关闭弹窗，官网其他内容继续正常使用。

## 测试与验收

### 自动测试

- 显示开关、时间边界和非法配置判断。
- 公告版本在图片或时间变化时改变，在仅切换开关时不改变。
- 普通关闭使用会话存储，“不再显示”使用本地存储。
- 后台开始/结束时间校验和韩英配置同步保存。
- 图片上传继续使用 S3 媒体流程。

### 浏览器验证

- 韩文和英文任意公开页面进入时均能显示。
- 时间开始前、结束后和关闭开关时均不显示。
- 普通关闭后同一会话内切换页面不再出现，新会话重新出现。
- 勾选“不再显示”后刷新、重新打开浏览器均不出现。
- 修改图片或时间后再次出现。
- 关闭按钮、遮罩、`Escape`、滚动锁定和焦点恢复可用。
- 手机与桌面视口中图片完整、无溢出、无控件遮挡。

最后执行相关单元测试、`npm run lint`、`npm run build`，本地 Docker 视觉检查通过后再提交、推送并部署 AWS。

## 不在本次范围

- 多公告并行或公告历史。
- 富文本、标题、正文和按钮链接。
- 按页面、语言或用户群定向。
- 浏览量、关闭率等弹窗统计。
- 视频弹窗。
