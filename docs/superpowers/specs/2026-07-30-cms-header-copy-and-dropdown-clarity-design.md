# CMS 顶部栏文案与下拉菜单辨识度设计

## 目标

让运营人员可以在现有 CMS 的 “Common / Navigation” 区域分别维护韩文、英文顶部栏的全部文字内容，并提高韩文版顶部栏及桌面下拉菜单的可读性和辨识度。

## 范围

顶部栏可编辑内容包括：

- 左侧品牌文字；
- 桌面端与移动端的主菜单、子菜单文字；
- 韩文、英文语言短标签；
- CONTACT 按钮文字；
- 桌面与移动端下拉菜单的 eyebrow、标题和各子项说明；
- 打开、关闭、展开、收起、主导航、移动导航及子菜单等辅助提示文字；
- 顶部栏使用的外部站点名称（继续使用现有外部站点编辑器）。

当前已有但未在管理界面展示的 `MAKING` 菜单字段也纳入此次修正。导航链接继续使用现有 CMS 字段，不改变路由结构。

## 数据与 CMS 设计

沿用 `common.navigation` 数据结构，不新增独立 Header 页面或第二套导航数据。

在 `common.navigation` 下补充品牌文字和语言短标签，并将当前页面实际读取的所有导航文字路径加入页面目录与 CMS 的导航字段分组。韩文与英文仍分别保存、分别回退到各自静态消息文件。

兼容处理遵循现有 CMS 合并规则：旧数据库中不存在的新字段使用静态消息中的默认值；运营人员明确保存的空字符串仍按现有规则保留，以支持不显示可选 eyebrow 等场景。外部站点名称继续由现有外部站点编辑器管理。

## 前台表现

### 韩文版顶部栏

在韩文 locale 的顶部栏根节点增加明确的 locale 样式标识。主导航、品牌、操作区、移动菜单、下拉标题与说明整体提高字重、字号和颜色对比度。调整只作用于顶部栏，不改变正文或页脚排版。

样式增强保持现有布局尺寸和响应式断点，避免文案变长后产生明显跳动；必要时保留当前横向滚动和收缩行为。

### 桌面下拉菜单

保留当前全宽 mega menu 结构和动画，在菜单容器上增加完整、清晰的 1px 边框，并保留阴影。边框颜色应在白色及浅色页面背景上清晰可见，同时不抢过导航内容。

移动端不新增悬停行为，继续使用点击展开；其文案同步使用 CMS 数据和韩文可读性样式。

## 兼容性与无障碍

- 继续使用现有 `aria-label`、`aria-expanded`、键盘焦点和 Escape 关闭行为；
- 辅助提示文案也从 CMS 合并后的语言消息读取；
- 保留韩文、英文站点开关及 Golf 菜单开关；
- 不更改现有导航目标、激活状态判断或外部链接安全处理。

## 验证

- 增加 CMS 字段覆盖测试，确保顶部栏读取的全部文字路径均有对应编辑字段；
- 验证 `MAKING`、品牌文字、语言短标签和下拉菜单文案在韩文、英文 CMS 面板中出现；
- 验证前台不再硬编码品牌文字或语言短标签；
- 验证桌面下拉容器包含完整边框样式；
- 运行相关 Node 测试、类型检查、代码检查与完整测试套件；
- 在桌面和移动宽度下检查韩文版顶部栏的清晰度、换行和下拉菜单边界。

## 非目标

- 不重做顶部栏信息架构；
- 不新增菜单层级或拖拽排序；
- 不改变页面 URL；
- 不调整正文、页脚或管理后台的全局字体；
- 不引入新的 CMS 页面或数据表。
