# CMS 입력용 SEO 수정안 (daeho.works)

## 왜 이 문서가 필요한가

`daeho.works`의 페이지 제목·설명·본문은 **CMS 값이 코드보다 우선**합니다.

- 메타데이터: `lib/seo.ts`의 값은 폴백이며, `getCmsPageSeoOverride()`가 CMS 값을 먼저 적용합니다.
- 본문: `lib/locale-messages.ts`가 `messages/ko.json`을 읽은 뒤 `applyCmsPageOverrides()`로 CMS 콘텐츠를 덮어씁니다.

즉 아래 항목들은 **코드 배포로 반영되지 않으며, CMS 관리자 화면에서 직접 입력해야** 운영 사이트에 적용됩니다.

## 작업 원칙

1. **타깃 키워드 5개**: 우승반지 제작 / 커스텀 트로피 / 기업 행사 기념품 / 스포츠 시상식 용품 / 커스텀 디자인 제작
2. **표기 규칙**: "맞춤" 대신 **"커스텀"**으로 통일합니다. **"주얼리"는 사용하지 않습니다.** 업종이 주얼리로 좁게 규정되면 트로피·기념품·시상식 용품 축과 어긋나기 때문입니다.
3. **없는 것을 있다고 쓰지 않습니다**: 커스텀 트로피·스포츠 시상식 용품은 사진과 사례 자료를 받기 전이므로, "제작 사례"처럼 실물이 이미 게재된 듯한 표현을 쓰지 않습니다. 자료 수령 후 별도로 반영합니다.
4. **임관반지는 현행 유지**: `daehogold.com`의 주력 키워드이므로 daeho.works에서는 우선순위만 낮춥니다. 기존 임관반지 콘텐츠는 삭제하거나 수정하지 않고, 신규로 작성하는 문구에만 넣지 않습니다.
5. **`/ko/mastery/creations/appointment`는 전혀 손대지 않습니다.** 임관반지 전용 지면이므로 제목·설명·본문 모두 현행 유지합니다.
6. **길이 기준**: 제목은 `| DAEHO` 포함 30~35자, 설명은 80자 내외. 한국어 검색결과에서 잘리지 않는 범위입니다.

| `/ko/heritage/loyalty` | 기업 행사 기념품 제작 신뢰 | 키워드와 "신뢰"가 접착제 없이 붙어 한국어로 부자연스러움 | **고객과의 약속** |
| `/ko/mastery/creations` | 우승반지·커스텀 트로피 제작 사례 | **트로피 사례가 아직 없는데 있는 것처럼 읽힘** | **우승반지·커스텀 디자인 제작 사례** |
| `/ko/mastery/making` | 우승반지·커스텀 트로피 제작 과정 | 같은 이유. 본문은 반지 공정만 다룸 | **우승반지 제작 공정** |

`/ko/heritage/loyalty`의 h1에는 타깃 키워드가 들어가지 않습니다. 자연스러움을 우선한 결과이며, **"기업 행사 기념품"은 같은 페이지의 제목·설명·본문이 담당**하므로 해당 키워드가 이 지면에서 사라지지는 않습니다.

### 디자인을 해치지 않는 적용 방법

**코드 수정이 필요 없습니다.** `components/legacy/heritage-hero.tsx`를 확인한 결과, 작은 라벨(`label`)과 큰 제목(`h1`)을 분리해 표시하는 구조가 **이미 구현되어 있습니다.**

```
HERITAGE · LOYALTY        ← 작은 라벨 (기존 구조, 그대로 유지)
고객과의 약속               ← h1 (CMS 값만 교체)
```

### 코드 기본값은 원래 한국어였습니다

`messages/ko.json`의 기본값과 운영 사이트의 실제 출력이 다릅니다. CMS에서 한국어 제목을 영문 단어로 덮어쓴 상태입니다.

| 페이지 | 코드 기본값 (`hero.title`) | 현재 운영 h1 |
|---|---|---|
| `/ko/heritage/loyalty` | 신의 | RELATIONSHIP |
| `/ko/heritage/credibility` | 신뢰 | STANDARD |
| `/ko/heritage/achievement` | 성취 | RESULT |

따라서 이 작업은 **CMS 값을 한국어로 되돌리면서 검색 키워드를 함께 반영**하는 것이며, 배포 없이 즉시 적용됩니다.

**주의**: 눈에 보이는 변경이므로 위 표의 변경안을 승인해 주신 뒤 입력하겠습니다.

## 6. 확인이 필요한 사항

### 6-1. 커스텀 트로피·스포츠 시상식 용품 — 콘텐츠 대기 중

**취급 여부는 확인되었습니다.** 실제로 제작하신다고 회신 주셔서 구조화 데이터의 해당 항목을 그대로 유지합니다.

다만 사이트 전체 검색 결과 **"트로피" 0건, "시상" 0건, "메달" 0건**으로, 두 키워드를 뒷받침할 본문이 아직 없습니다. 구글은 본문에서 근거를 찾지 못하면 입력한 설명을 무시하고 스니펫을 자체 생성하므로, **메타데이터만으로는 검색 유입을 기대하기 어렵습니다.**

**대기 중**: 제품 사진과 제작 사례를 전달해 주시면 전용 페이지를 구성하겠습니다. 이 두 키워드는 뒷받침할 콘텐츠 확보가 선행되어야 합니다.

### 6-2. FAQ 구조화 데이터 — 콘텐츠 대기 중 (우선순위 낮음)

**기대치를 정확히 맞춰 드립니다.** 구글은 2023년부터 FAQ 구조화 데이터의 검색결과 확장 표시를 정부·의료 등 일부 기관으로 제한하고 있어, **일반 기업 사이트에서는 질문·답변이 펼쳐지지 않습니다.**

다만 검색엔진과 AI 검색이 페이지 내용을 이해하는 근거로는 여전히 활용됩니다.

**대기 중**: 자주 받으시는 질문 5~10개를 전달해 주시면 페이지와 스키마를 함께 구성하겠습니다. 질문을 임의로 지어내면 구조화 데이터 정책 위반이라 진행할 수 없습니다. 우선순위가 높지 않으니 여유 있으실 때 주셔도 됩니다.

### 6-0. 뉴스 발행일이 `2026.00.00`으로 입력되어 있습니다 (신규 발견)

3차 PR 검증 중 확인한 사항입니다. **뉴스 6건 전부 발행일이 `2026.00.00`으로 저장되어 있습니다.**

```
news-01 ~ news-06   publishedAt = "2026.00.00"
```

`messages/ko.json`의 기본값과 CMS 값이 모두 같아, 운영 사이트 뉴스 목록에도 `2026.00.00`이 그대로 노출됩니다.

**영향 두 가지**

1. **화면**: 방문자에게 날짜가 `2026.00.00`으로 보입니다.
2. **구조화 데이터**: 월·일이 `00`이라 실재하지 않는 날짜입니다. Article 스키마의 `datePublished`는 유효한 날짜만 출력하도록 검증을 넣어 두었으므로, 현재는 **6건 모두 `datePublished` 없이 출력**됩니다.

`2026-00-00`을 그대로 내보내면 리치 결과 테스트에서 오류가 나므로 생략하는 쪽이 맞습니다. 다만 발행일은 뉴스 콘텐츠의 기본 신호라 **실제 날짜를 넣으시는 편이 좋습니다.**

**요청**: 뉴스 6건의 실제 발행일을 알려 주시거나 CMS에서 직접 입력해 주세요. 입력하시면 코드 변경 없이 `datePublished`가 자동으로 채워집니다. 입력 형식은 `2026-07-17`, `2026.7.17`, `2026년 7월 17일` 모두 인식합니다.

### 6-3. 캐시 정책 — 고객사 구현 완료 (이 문서 항목 종료)

이전 판에서 "현행 유지, 별도 PR로 개선안 제안 예정"으로 적었던 항목입니다. **그 사이 고객사 개발팀이 직접 구현해 최신 main에 반영했으므로 서술을 정정합니다.**

앞서 제안드린 온디맨드 재검증 방식(캐시해 두되 저장 시점에 해당 페이지만 무효화)이 그대로 구현되어 있습니다.

| 구현 항목 | 위치 |
|---|---|
| 공개 페이지 1시간 캐시 | `app/[locale]/(site)/layout.tsx` — `revalidate = 3600` |
| 공개 CMS 조회 캐시 | `lib/cms/repositories.ts:761` — 태그 기반 `force-cache` |
| 페이지·뉴스·작품 저장 시 무효화 | `lib/cms/public-cache.ts` — 태그와 경로를 함께 처리 |

```bash
# 1. 페이지별 제목·설명이 반영됐는지 확인

done

for p in /mastery/technique /news /contact; do
  curl -s "https://daeho.works/ko$p" | grep -oE '<meta property="og:image" content="[^"]*"'

curl -s https://daeho.works/ko/mastery/creations/appointment | grep -oE '<title>[^<]*</title>'
# 기대값: 대호 임관반지 제작 | DAEHO
```
