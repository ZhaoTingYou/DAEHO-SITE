# CMS 입력용 SEO 수정안 (daeho.works)

## 왜 이 문서가 필요한가

`daeho.works`의 페이지 제목·설명·본문은 **CMS 값이 코드보다 우선**합니다.

- 메타데이터: `lib/seo.ts`의 값은 폴백이며, `getCmsPageSeoOverride()`가 CMS 값을 먼저 적용합니다.
- 본문: `lib/locale-messages.ts`가 `messages/ko.json`을 읽은 뒤 `applyCmsPageOverrides()`로 CMS 콘텐츠를 덮어씁니다.

즉 아래 항목들은 **코드 배포로 반영되지 않으며, CMS 관리자 화면에서 직접 입력해야** 운영 사이트에 적용됩니다.

## 작업 원칙

1. **타깃 키워드 5개**: 우승반지 제작 / 커스텀 트로피 / 기업 행사 기념품 / 스포츠 시상식 용품 / 맞춤 주얼리 제작
2. **임관반지는 현행 유지**: `daehogold.com`의 주력 키워드이므로 daeho.works에서는 우선순위만 낮춥니다. 기존 임관반지 콘텐츠는 삭제하거나 수정하지 않고, 신규로 작성하는 문구에만 넣지 않습니다.
3. **`/ko/mastery/creations/appointment`는 전혀 손대지 않습니다.** 임관반지 전용 지면이므로 제목·설명·본문 모두 현행 유지합니다.
4. **길이 기준**: 제목은 `| DAEHO` 포함 30~35자, 설명은 80자 내외. 한국어 검색결과에서 잘리지 않는 범위입니다.

## 5. 확인이 필요한 사항

### 5-1. 커스텀 트로피·스포츠 시상식 용품 — 실제 취급 여부 확인 요청

사이트 전체를 검색한 결과 **"트로피" 0건, "시상" 0건, "메달" 0건**입니다. 두 키워드를 뒷받침할 콘텐츠가 현재 없습니다.

- 메타데이터와 구조화 데이터에는 신호를 심어두었습니다.
- 다만 **본문 콘텐츠 없이 메타데이터만으로는 순위가 형성되지 않습니다.** 구글은 본문 근거가 없으면 메타 설명을 무시하고 스니펫을 자체 생성합니다.

**확인 요청 2가지**

1. 대호가 실제로 트로피·시상식 용품을 제작하십니까? 제작하지 않는다면 구조화 데이터에서 해당 항목을 제거하겠습니다.
2. 제작하신다면 제품 사진과 사례를 제공해 주시면 전용 콘텐츠를 구성하겠습니다. 이 두 키워드의 순위 확보에는 이 작업이 필수입니다.

### 5-2. FAQ 구조화 데이터 — 콘텐츠 필요

FAQ 스키마는 검색결과 노출 면적을 넓히지만, 현재 사이트에 FAQ 콘텐츠가 없습니다. 실제로 자주 받으시는 질문 5~10개를 주시면 페이지와 스키마를 함께 구성하겠습니다. 질문을 임의로 지어내면 구조화 데이터 정책 위반이라 진행할 수 없습니다.

### 5-3. 캐시 정책 — 성능과 콘텐츠 즉시성의 트레이드오프

전 118페이지가 `Cache-Control: private, no-cache, no-store`로 응답하며, TTFB 중앙값이 636ms(최대 896ms)입니다.

- 캐시를 허용하면 응답 속도가 개선됩니다.
- 대신 CMS 수정이 사이트에 즉시 반영되지 않습니다.

운영 정책에 관한 판단이라 임의로 변경하지 않았습니다. 결정해 주시면 반영하겠습니다.

## 6. 입력 후 검증 방법

```bash
# 1. 페이지별 제목·설명이 반영됐는지 확인
for p in "" /archive /heritage/loyalty /heritage/credibility /heritage/achievement \
         /mastery/making /mastery/technique /mastery/creations /news /contact; do
  echo "--- /ko$p"
  curl -s "https://daeho.works/ko$p" \
    | grep -oE '<title>[^<]*</title>|<meta name="description" content="[^"]*"'
done

# 2. og:image가 페이지마다 다른지 확인
for p in /mastery/technique /news /contact; do
  curl -s "https://daeho.works/ko$p" | grep -oE '<meta property="og:image" content="[^"]*"'
done

# 3. 임관반지 전용 페이지가 그대로인지 확인
curl -s https://daeho.works/ko/mastery/creations/appointment | grep -oE '<title>[^<]*</title>'
# 기대값: 대호 임관반지 제작 | DAEHO
```

구조화 데이터는 [리치 결과 테스트](https://search.google.com/test/rich-results)에 URL을 넣어 Organization·Service·Article이 오류 없이 인식되는지 확인하실 수 있습니다.
